# Third-party components and content

This inventory describes the source snapshot. No endpoint was contacted or validated during preparation. Provider endpoints can change, restrict access or stop working. Users must check provider terms before using or redistributing these integrations. Public accessibility does not grant content or redistribution rights.

## Components and source license

`app/build.gradle.kts` lists AndroidX, Kotlin coroutines, OkHttp, Coil, JUnit and org.json coordinates; the root build and wrapper pin Kotlin, Android Gradle Plugin and Gradle. These components keep their own licenses. Preserve applicable dependency notices when distributing binaries. Project-owned source is licensed under the included MIT license. It does not license third-party services, content or trademarks.

The JAR was checked without executing it. This verifies the bundled wrapper file, not a build or downloaded distribution.

## Network sources and references

All source paths below are relative to `app/src/main/java/com/majendra/tvlauncher/`.

| Source | Use and limits | Source file |
| --- | --- | --- |
| Open EPG, `https://www.open-epg.com/files/australia.xml.gz` | National XMLTV-format schedules, filtered to Kayo channels and cached locally. Open EPG supplies metadata; this is not an official Kayo API and provides no stream or subscription. | `providers/KayoGuide.kt`, `providers/KayoProvider.kt` |
| XMLTV.net, `https://xmltv.net/xml_files/Melbourne.xml` | Melbourne broadcast schedules for retained tuner/broadcaster matching. Tuner sections are hidden on the Chromecast variant. XMLTV is also a data format; it is distinct from Open EPG and the XMLTV.net operator. | `providers/LiveTvProvider.kt` |
| Seven, `https://component-cdn.swm.digital/content/live-tv?platform-id=web&market-id=26&platform-version=1.0.67393&api-version=5.9.0.0` | Region/version-specific live-channel metadata for 7plus. No guarantee of a supported developer API, playback entitlement or continued compatibility. | `providers/BroadcasterExtras.kt` |
| 9Now, `https://api.9now.com.au/ctv/livestreams?device=web&region=vic&offset=0` | Victoria live-channel metadata. No account or token is supplied; this does not establish permission to play or redistribute streams. | `providers/BroadcasterExtras.kt` |
| YouTube, `https://www.youtube.com/youtubei/v1/search?prettyPrint=false`, `i.ytimg.com` | Unofficial InnerTube logged-out web search and thumbnails, plus native Android recommendation rows. InnerTube is not the supported YouTube Data API. It sends the Windows desktop Chrome User-Agent `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0 Safari/537.36`. This unofficial request may conflict with YouTube's terms; users must review those terms before using it. No launcher Google login/API key is configured. Response changes or access restrictions may break search. Native recommendation rows may reflect the separate YouTube app's activity. | `providers/youtube/InnerTube.kt`, `providers/YouTubeProvider.kt` |
| Cinemeta, `v3-cinemeta.strem.io`, `cinemeta-catalogs.strem.io`; artwork from `images.metahub.space`, with some ABC artwork paths allowing `image.tmdb.org` | Public discovery, search, title/episode metadata and artwork. No Stremio account library or private add-on configuration is loaded in this edition. Metadata does not supply a playable video. | `providers/StremioDiscoveryProvider.kt`, `providers/StremioMetadataClient.kt`, `providers/cinemeta/`, `providers/KidsCornerProvider.kt` |
| ABC, `api.iview.abc.net.au/v3`, `cdn.iview.abc.net.au`, `iview.abc.net.au/video/`, `www.abc.net.au/news/feed/2942460/rss.xml` | ABC programme metadata/artwork, playback handoffs and sports news. App availability and playback terms remain separate. | `providers/AbcNowNext.kt`, `providers/KidsCornerProvider.kt`, `providers/sports/SportsNews.kt` |
| `https://www.classification.gov.au/titles/` and `https://www.stan.com.au/watch/` | Provenance URLs attached to curated Australian G-rated seeds. The code constructs these references from seed data; it does not fetch those pages or perform a current classification audit. Kids Corner is not a parental-control boundary inside other apps. | `providers/KidsCornerProvider.kt`, `providers/KidsClassificationPolicy.kt` |
| ESPN, `site.api.espn.com` | Scoreboards, match details, standings, artwork and news. No provider account is configured. Endpoint presence does not establish a supported API contract or redistribution permission. | `providers/sports/EspnScores.kt`, `providers/sports/SportsNews.kt`, `sportscentre/SportsDataRepository.kt` |
| Wikipedia/Wikimedia, `en.wikipedia.org/w/api.php` and returned public image hosts | Channel-logo lookup in retained TV compatibility code. Images may have individual attribution/license requirements. | `providers/ChannelLogoLookup.kt`, `LauncherApplication.kt` |
| Squiggle, `https://api.squiggle.com.au/` | Dormant AFL standings/fixture/live-score implementation remains in `sportscentre/SportsDataRepository.kt`. `configuredContact()` always returns null and the contact-email form is removed, so these requests are disabled. Re-enabling would send the configured contact email in the HTTP User-Agent and requires renewed terms/privacy review. ESPN remains the active score source. | `sportscentre/SportsDataRepository.kt` |

Service names and Android package IDs identify external playback/compatibility destinations and belong to their owners. No fetched feed dumps, posters, logos, videos, account exports, cookies, credentials or subscriptions are bundled. Some curated title/classification seed metadata is present in source. Verify rights and notices for any binary or content redistribution separately.
