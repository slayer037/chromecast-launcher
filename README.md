# Chromecast Launcher

A native Kotlin launcher for Chromecast with Google TV. Browse public movie and TV catalogues, sports schedules and scores, Kids Corner, and installed streaming apps using a remote.

Only `bedroomRelease` is documented and supported by this source package. The `debug` and `release` variants are not covered by the no-live-TV, quiet-hours or Chromecast-safety guidance below. Their defaults differ; use the documented variant.

## No launcher login

This edition has no account setup, pairing-code login, API key or backend to configure. Stremio account linking and session storage are removed. Watched choices stay on the device. Screensaver wall/phone access and remote watched sync are not included. Kayo profiles are selected manually in Kayo.

Playback opens another installed app. Those apps may require their own login, subscription, regional access or source selection. This launcher does not provide video streams, subscriptions or access to paid content. Google TV device onboarding and app-store requirements are separate from the launcher.

## Build from source

Use JDK 17, Android SDK platform 35 and a network connection to download dependencies. The wrapper pins Gradle 8.13; the project pins Android Gradle Plugin 8.13.2 and Kotlin 2.3.10. Minimum Android API is 26, target API is 34.

1. Extract this directory into a fresh workspace. Do not copy the private parent project or its Git history.
2. Install the Android SDK with Android Studio or command-line tools. Set `ANDROID_HOME` to your SDK directory, or create an untracked `local.properties` with `sdk.dir` pointing to it. Set `JAVA_HOME` to JDK 17.
3. On Windows run `./gradlew.bat --no-daemon :app:assembleBedroomRelease`. On macOS/Linux use `sh ./gradlew --no-daemon :app:assembleBedroomRelease`.
4. The APK is `app/build/outputs/apk/bedroomRelease/app-bedroomRelease.apk`. This developer build uses your local Android debug signing key, generated by Android tooling. No signing key is distributed. Choose and protect a release signing key before distributing APKs; different signing keys cannot update one another.

The public application ID is `com.majendra.tvlauncher.opensource`, a distinct public owner-brand identifier under the existing project namespace. The private app uses `com.majendra.tvlauncher`, so the public build installs separately with its own app storage and does not update or migrate the private app. The Kotlin namespace remains `com.majendra.tvlauncher` as the public owner-brand namespace for source classes; the Sports Centre screensaver settings component uses the public install ID with the existing class namespace. Global application-ID collisions have not been verified. Compilation, device installation and remote acceptance have not been performed for this export.

## Install and choose Home

On your own awake device, enable developer options and Android's wireless debugging. Use Android SDK Platform Tools to pair/connect manually using the endpoint currently displayed by that device. Keep pairing codes and addresses private. Install the APK with `adb -s <YOUR_DEVICE_ENDPOINT> install app/build/outputs/apk/bedroomRelease/app-bedroomRelease.apk`. This is an instruction for your device; the package contains no saved device targets or install automation.

Open **Chromecast Launcher** from the app list. If Android offers a Home chooser, select it there. Home handling varies by firmware; installation alone does not change the default Home app. Optional Home compatibility requires an explicit accessibility grant in Android Settings. Keep the original Google TV Home enabled and available for recovery. This package does not require disabling system packages, granting secure-settings access, changing radios or rebooting.

Use Left/Back to return to the sidebar, OK to open a card, and hold OK for item actions. Settings offers device settings, feed visibility, sidebar order and local watched choices. If a source or playback app is unavailable, other launcher sections remain usable. Android may request TV-listings permission for native recommendation rows; public catalogue browsing does not need account linking.

## Chromecast behaviour and recovery

Use `bedroomRelease`: it hides tuner/live-TV sections and Stremio live channels while keeping catch-up apps and Kayo streaming schedules. Movie/TV genre rows, filters, picker, upcoming episodes and resting-focus previews remain. Catalogue work is bounded to two workers, two popular pages per genre and 40 titles per row. Other sections have no previews or focus zoom/shadows.

The inherited optional automatic Home handoff blocks automatic launches from 20:00 through 07:59 Australia/Sydney, including DST, and while asleep. Manual remote actions remain available. There is no scheduled wake, restart or install automation. Wi-Fi and Bluetooth remain under Android's normal controls.

To recover, open Android Settings and select the original Home app where supported, disable this launcher's accessibility service, or uninstall `com.majendra.tvlauncher.opensource` from Apps. Uninstalling removes its local preferences and watched choices. The recovery instructions here use Android Settings only.

## Schedule and catalogue sources

Kayo schedules come from Open EPG at `https://www.open-epg.com/files/australia.xml.gz` (`KayoGuide.SOURCE`). The retained tuner implementation separately uses XMLTV.net at `https://xmltv.net/xml_files/Melbourne.xml` (`LiveTvProvider.SOURCE`); tuner sections are hidden in `bedroomRelease`. These are third-party schedule feeds, not a Kayo API or proof that a programme can play.

See [THIRD_PARTY.md](THIRD_PARTY.md) for Seven/9Now metadata, unofficial YouTube InnerTube, classification references and the disabled Squiggle integration. Provider endpoints can change or stop working. Users must check provider terms before using or redistributing these integrations.
