# Privacy and service disclosures

The launcher fetches public HTTPS metadata, artwork, search results, schedules, scores and news. Requests expose your IP address and requested titles/search terms to the contacted providers and may send an app User-Agent. There is no configured analytics collector, cloud backend, watched sync, launcher login or credential form. Playback opens external apps, whose accounts, subscriptions, regional rules and privacy policies are separate.

Open EPG supplies the Australia schedule feed used for Kayo; retained TV compatibility code also uses XMLTV.net's Melbourne feed. Seven and 9Now endpoints supply region-specific channel metadata. Unofficial YouTube InnerTube supplies logged-out search, with YouTube thumbnail hosts and optional native Android recommendation rows. InnerTube sends this Windows desktop Chrome User-Agent: `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0 Safari/537.36`. This unofficial request may conflict with YouTube's terms; users must review those terms before using it. Native rows may reflect activity in the separately installed YouTube app. Cinemeta/MetaHub, ABC, ESPN and Wikipedia/Wikimedia are also represented in the code. See [THIRD_PARTY.md](THIRD_PARTY.md) for endpoints, source files and limits.

classification.gov.au and stan.com.au URLs are classification provenance links built from curated seeds. They are not fetched as part of classification lookup, and the app does not verify those ratings live. Any external opening of a reference is subject to that site's policies. Kids Corner does not restrict what another playback app can show.

The dormant Squiggle integration is disabled: `configuredContact()` always returns null and its contact-email form is removed. It makes no Squiggle requests in this edition. If re-enabled, that implementation would transmit a configured contact email in its User-Agent; review and update these disclosures first.

Preferences, starred titles, watched choices and diagnostic events remain in Android app storage; public feed and artwork caches also use local storage. Android backup is disabled. Local encryption keys protect preferences and are not provider credentials. Review logs before sharing because titles, installed-app state and navigation details can be personal. Uninstalling removes app-local state.

Stremio account transport/session storage are empty adapters; the account link UI and ticket model are removed. Private wall settings/services/key storage and watched-sync bearer transport are removed; watched choices use a local-only facade. The optional accessibility service handles Home/navigation events with screenshot and gesture capabilities disabled; Kayo profiles stay manual. Wireless-debugging recovery and its startup callers are removed; the launcher does not change Android debugging settings.

Provider endpoints can change or stop working. Users must check provider terms before using or redistributing these integrations. These disclosures describe source behaviour, not live provider verification or permission to redistribute content. The MIT source license does not grant rights to provider content.
